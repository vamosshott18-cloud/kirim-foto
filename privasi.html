Kebijakan Privasi — Kirim Foto

Berlaku sejak 22 Oktober 2026 · Kembali ke aplikasi

Apa itu Kirim Foto

Kirim Foto adalah aplikasi web untuk mengolah foto (preset warna, watermark, ukuran, nama file) lalu mengirimnya ke Google Drive, Google Photos, atau menyimpannya ke perangkat pengguna.

Data yang diakses

  • Foto & video yang kamu pilih — diolah langsung di perangkat kamu (di browser). Tidak dikirim ke server Kirim Foto.
  • Google Drive (izin drive.file) — hanya file & folder yang dibuat oleh Kirim Foto. Aplikasi tidak bisa melihat file Drive lain milikmu.
  • Google Photos (izin tambah & kelola foto yang ditambahkan aplikasi) — membuat album dan menambahkan foto hasil export. Aplikasi tidak bisa melihat foto lain di Google Photos-mu.
  • Alamat email akun Google — ditampilkan di aplikasi supaya kamu tahu akun mana yang sedang dipakai.

Yang disimpan

  • Preset, logo watermark, dan pengaturan disimpan di browser perangkat kamu sendiri.
  • Supaya kamu cukup login sekali, layanan login Kirim Foto (Google Apps Script) menyimpan token izin akun Google-mu, terhubung dengan nomor sesi acak di perangkatmu. Token ini hanya dipakai untuk memperpanjang akses Drive/Photos di atas. Foto tidak pernah lewat layanan ini.
  • Tekan Keluar di aplikasi untuk menghapus token tersebut. Kamu juga bisa mencabut akses kapan saja di myaccount.google.com/permissions.

Yang tidak kami lakukan

  • Tidak menjual, membagikan, atau memakai datamu untuk iklan.
  • Tidak menyimpan salinan foto di server mana pun selain tujuan yang kamu pilih (Drive/Photos milikmu atau perangkatmu).

Penggunaan data dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.
